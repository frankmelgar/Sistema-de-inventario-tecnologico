# Copy Para LinkedIn

Hoy terminé **SMART TECH SOLUTIONS**, una tienda tecnológica construida con **PHP + MySQL** enfocada en una experiencia comercial clara, moderna y administrable.

Incluye:

- catálogo dinámico por categorías y marcas
- panel administrativo para productos, branding y pedidos
- carrito y checkout con registro de compra
- estructura lista para reutilizar como base de futuros proyectos

Más que una demo visual, quise trabajar una base funcional que pudiera convertirse en una solución real para pequeños negocios tecnológicos.

Tecnologías: `PHP`, `MySQL`, `Bootstrap`, `HTML`, `CSS`, `JavaScript`

Siguiente paso: seguir iterando el producto, mejorar automatizaciones y preparar una versión aún más sólida para producción.

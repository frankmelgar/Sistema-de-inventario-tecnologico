# SMART TECH SOLUTIONS

Tienda tecnológica desarrollada en PHP y MySQL con panel administrativo, catálogo dinámico, carrito de compra y checkout con registro de pedidos.

## Resumen

SMART TECH SOLUTIONS es un prototipo comercial orientado a la venta de dispositivos, portátiles, tablets, accesorios y procesadores. El proyecto está pensado como base reutilizable para demostraciones, portafolio y adaptación a negocios tecnológicos.

## Funcionalidades principales

- Catálogo público con filtros por categoría y marca
- Productos destacados y control de visibilidad
- Carrito de compra con actualización de cantidades
- Checkout con datos de cliente, dirección y método de pago
- Panel administrativo para productos, branding y pedidos
- Personalización visual desde base de datos
- Gestión de imágenes de producto y placeholders dinámicos

## Tecnologías

- PHP
- MySQL
- Bootstrap 5
- HTML, CSS y JavaScript
